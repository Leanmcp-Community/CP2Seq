# Probe C 阶段一 · simple-foldability 必要条件筛选

**状态：完成（2026-09-15）** · 脚本 `workspace/probe-c/screen.mjs` · 语料 instagram n=366

## 结论

> **至少 46.7% 的真实折纸作品，已被证明无法用 all-layers simple fold 折出。**

两条独立的证据叠加得到：贯穿线判据排除 34.2%，**预折痕痕迹**再排除 12.6%。
这不是让步，是实测出来的范围边界 —— 论文可以直接引用。

## 判据（精确，必要不充分）

第一折作用在单层平纸上 → 必须沿一条**贯穿边界到边界的直线** → 单层只能往一个方向折
→ **该线折痕 M/V 必须一致**。纯 simple folding 没有展开操作，所以那条线一定留在最终 CP 里。
**没有这样的线 ⇒ 一定不可 simple fold。**

## 结果

| | |
| --- | --- |
| 有贯穿边界到边界的折痕线 | 307/366 = 83.9% |
| **…其中至少一条方向一致** | **241/366 = 65.8%** ← 可折的**上界** |
| **失败 ⇒ 已证明不可折** | **125/366 = 34.2%** |
| 　无贯穿线 / 有线但从不一致 | 59 / 66 |

**规模画像**：通过者面数 p50 = 174，失败者 p50 = 477 → **复杂作品用不了 simple fold**。

## 预折痕：把上界再压低 12.6 个百分点

**论证**：纯 all-layers simple folding **没有展开操作**，所以一条折角为 0 的折痕
（FOLD 里的 `F`）在它产出的 CP 里根本不可能存在。**任何真·预折痕都是动作空间之外的动作留下的
痕迹** —— 带这种痕迹却通过了贯穿线判据的 CP，是**假阳性**：判据放过了它，但它本来就不是
simple fold 折出来的。

### 先解决 `F` 的歧义（27 个存疑的已判掉）

`F` 在 FOLD 里既是「折角为 0 的真折痕」，也可能是导出器三角剖分产生的 **facet 伪边**。
上一版把 27 个 CP 挂成「存疑」。**现在判掉了，靠实测不靠假设**：

| 证据 | 结果 |
| --- | --- |
| **三角剖分是整模型级的操作**，没有人只剖一个面 | **没有任何一个 CP 是全三角剖分的**。69 个含 F 的 CP 里三角面占比最高的是 `058_ku_Color-change_Pinwheel_1` 的 **90.9%** —— 而这个比例在鸟基/蛙基类作品里就是正常几何，不是导出痕迹 |
| 单条边的 facet 特征（两侧面都是三角形） | 只有 **918/10,827 = 8.5%** 的 F 边符合，而且**没有任何一个 CP 的 F 边全部是这一类** |

→ **这批语料里 facet 污染为零。每一条 `F` 边都是真折痕。** 27 个存疑的全部转为假阳性。

脚本仍然单独统计 `fFacet`（可疑边）和 `fSpan`（贯穿的 F 线，最强证据），结论可复核。

## 预折痕不纳入动作空间（已定 2026-09-15）

**不纳入。** 理由不是嫌麻烦，是它会拆掉这个探针本身：

- 一旦允许 fold-then-unfold，「纯 simple folding 没有展开操作 ⇒ 第一折的线必然留在最终 CP 里」
  这句话失效 → **判据失效 → 34.2% 和 40.2% 两个下界一起作废**
- 阶段二的「倒着拆」也失效 —— 不再有「最后一步必是全宽折线」
- 搜索空间从有限的单调拆解变成带撤销的图搜索。T4 证了**不带**撤销就已经 NP-hard

**处理方式**：当作**实测出来的范围边界**报，不建模。这正是上面那 6.0% 的来源 ——
它让论文的范围声明更硬，而不是更软。

## 阶段二 · 完整搜索（代码已写完，**尚未跑**）

`workspace/probe-c/stage2.mjs` · 运行：`bash workspace/probe-c/run-stage2.sh`
输入 = 阶段一留下的 **195 个 CP**（241 通过 − 46 个预折痕假阳性），由
`stage1-verdicts.json` 传递，两个阶段不会走偏。

**为什么正向模拟可行**：all-layers simple fold 把整叠纸沿一条直线刚性翻过去，
所以**永远不会自穿透，也没有任何层序约束**。可折性因此是纯几何问题，
不需要层序组合 —— 这正是能从方纸直接正向搜的原因。

**状态** = 一组**层**，每层带 (当前平面里的多边形, 原纸坐标↔当前平面的等距变换, 翻面奇偶性)。
**一折** = 用直线切开每一层、把动的那半反射过去、奇偶性取反；
直线在每层上截出的弦回拉到原纸坐标，**就是这一折造出的折痕 —— 一折一次造出多条**。
这个非局部耦合就是问题难的地方。

**剪枝**（让搜索有限的关键）：一折造出的每条折痕都必须已经在目标 CP 里、位置对、M/V 一致。
候选直线只取目标折痕线的像 → 分支因子是**目标折痕线数**，不是全平面的直线。

**M/V 不用分支**：一折只有一个方向。奇偶性 0 的层往上折写 V、翻过面的写 M，往下折相反。
方向直接从目标读出来再查一致性。

**三分报告，三者含义不同**：

| | |
| --- | --- |
| **SOLVED** | 找到序列 |
| **EXHAUSTED** | 搜索空间穷尽仍无解 ⇒ **证明不可折** |
| **TIMEOUT** | 用尽预算，状态未知。T4 保证这一桶非空 —— **单独报，绝不并进 EXHAUSTED** |

**预算按 query 数（模拟折叠次数）而不是墙钟**，所以数字可复现 ——
而 query 数正是论文效率主张要对标的纯搜索基线。

冒烟测试（已验证能跑，不是结果）：`009_ku_Unassigned_Triangle_Pleat` → SOLVED，
176 queries / 9 步 / 9ms；`001_traditional_Sailboat` → 5 万 queries 用完仍 TIMEOUT（119ms）。
**难度立刻显现，符合 T4 的预期。**
