# Probe C 阶段一 · simple-foldability 必要条件筛选

**状态：完成（2026-09-15）** · 脚本 `workspace/probe-c/screen.mjs` · 语料 instagram n=366

## 结论

> **至少 40.2% 的真实折纸作品，已被证明无法用 all-layers simple fold 折出。**

两条独立的证据叠加得到：贯穿线判据排除 34.2%，**预折痕痕迹**再排除 6.0%。
这不是让步，是实测出来的范围边界 —— 论文可以直接引用。

## 判据（精确，必要不充分）

第一折作用在单层平纸上 → 必须沿一条**贯穿边界到边界的直线** → 单层只能往一个方向折
→ **该线折痕 M/V 必须一致**。纯 simple folding 没有展开操作，所以那条线一定留在最终 CP 里。
**没有这样的线 ⇒ 一定不可 simple fold。**

## 结果

| | |
| --- | --- |
| 有贯穿边界到边界的折痕线 | 307/366 = 83.9% |
| **…其中至少一条方向一致** | **241/366 = 65.8%** ← 可折的**上界** |
| **失败 ⇒ 已证明不可折** | **125/366 = 34.2%** |
| 　无贯穿线 / 有线但从不一致 | 59 / 66 |

**规模画像**：通过者面数 p50 = 174，失败者 p50 = 477 → **复杂作品用不了 simple fold**。

## 预折痕：把上界再压低 6 个百分点

**论证**：纯 all-layers simple folding **没有展开操作**，所以一条折角为 0 的折痕
（FOLD 里的 `F`）在它产出的 CP 里根本不可能存在。**任何真·预折痕都是动作空间之外的动作留下的
痕迹** —— 带这种痕迹却通过了贯穿线判据的 CP，是**假阳性**：判据放过了它，但它本来就不是
simple fold 折出来的。

⚠️ **`F` 在 FOLD 里是歧义的**：导出器也用它标记三角剖分产生的 **facet 边**，那根本不是折痕。
用两个信号分开，分开报，不合并：

| 信号 | 含义 |
| --- | --- |
| **贯穿的 F 线** | F 折痕连成一条贯穿边界到边界的线。simple fold 留下的预折痕跨整张纸（和判据同一个论证）；三角剖分的对角线是内部边，不贯穿。**强证据** |
| **全三角面** | 每个面都是三角形 = 三角剖分导出的特征，其 F 边推定为 facet 伪边，**不计入** |

| | |
| --- | --- |
| 含任意 `F` 边的 CP | 69/366（共 10,827 条 F 边） |
| 全三角剖分的 CP | **1** ← facet 污染比担心的小得多 |
| **通过判据中：确证有预折痕** | **22** ← **假阳性** |
| 通过判据中：存疑（有 F，但只在内部 / 全三角） | 27 ← **不计入**，悬而未决 |

| 不可 simple fold 的下界 | |
| --- | --- |
| 仅判据 | 125/366 = 34.2% |
| **判据 + 确证预折痕** | **147/366 = 40.2%** |
| → 可折的上界 | 65.8% **降到 59.8%** |

**方向是对的**：22 个是保守计数（27 个存疑的没算），所以 40.2% 仍然是**下界**。

代表性案例：`092_ku_4_Stripes_2`（6 条贯穿 F 线）、`164_ku_Pleats_Exponential`（4 条）——
pleat 类作品靠预折痕定位，正是这个动作最典型的用途。

> 📌 两个 14% 别混淆：这里说的是 instagram 366 个 CP 里 **22/241 = 9.1%** 的通过者带预折痕；
> 下面「阶段二」提到的 14% 是 PurelandFold **337 帧里 47 帧**是预折痕**步骤**。
> 一个是 CP 层面的痕迹，一个是序列层面的动作，两个数不可比。

## 健壮性检查（报数之前做的）

1. **边界标注**：366 个文件全部含 `B` 边 → 边界顶点识别可靠
2. **`U` 边**：语料有 3,813 条方向未指定的边。忽略它们会两头偏 → 改为当通配并同时报严格版。
   影响很小（**仅 9/366 个 CP 含 U**，上界 64.8% → 65.8%）→ **结论稳健**

`edges_assignment` 分布：V 196,550 / M 190,173 / B 21,262 / F 10,827 / U 3,813。

⚠️ `009_ku_Unassigned_Triangle_Pleat`、`012_ku_4x4_Grid_Unassigned` 的折痕**全是 U**，
靠通配通过，引用时单独标注。

## 预折痕不纳入动作空间（已定 2026-09-15）

**不纳入。** 理由不是嫌麻烦，是它会拆掉这个探针本身：

- 一旦允许 fold-then-unfold，「纯 simple folding 没有展开操作 ⇒ 第一折的线必然留在最终 CP 里」
  这句话失效 → **判据失效 → 34.2% 和 40.2% 两个下界一起作废**
- 阶段二的「倒着拆」也失效 —— 不再有「最后一步必是全宽折线」
- 搜索空间从有限的单调拆解变成带撤销的图搜索。T4 证了**不带**撤销就已经 NP-hard

**处理方式**：当作**实测出来的范围边界**报，不建模。这正是上面那 6.0% 的来源 ——
它让论文的范围声明更硬，而不是更软。
