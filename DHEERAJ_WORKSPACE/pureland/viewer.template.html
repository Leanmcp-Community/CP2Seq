What the darkness means. Each face is drawn at a height set by how many sheets sit underneath it, taken from the faceOrders relation that Flat‑Folder computes for every ground-truth state. Translucent sheets composite, so a region covered by nine layers reads nine times denser than a single sheet. Set Layer gap to zero to collapse the stack back to the true flat-folded state.

These are states, not actions. PurelandFold stores one row per (sequence, step) — a snapshot of the paper, never the fold that produced it. Nothing in the data says “valley-fold along this line”; the action only exists as the difference between two consecutive frames.
