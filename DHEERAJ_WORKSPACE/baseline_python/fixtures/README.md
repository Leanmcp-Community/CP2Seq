`ladybug_step_04.fold` is the `cp.fold` snapshot from PurelandFold, sequence
`ladybug`, step 4, inspected on 2026-09-16. JSON whitespace was compacted; the
geometry and state fields were preserved. No intermediate frames are bundled.

Source: [mayaweiz/PurelandFold](https://huggingface.co/datasets/mayaweiz/PurelandFold),
by the FoldingAgent authors, Moriya, Raab, Vinker, and Dekel, per the repository's
Pureland audit. Dataset license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The fixture checks a real clockwise mesh, Pureland's world layer-order
convention, and a two-fold solution that moves multiple faces at a time. It is
a regression case, not a representative full-dataset performance result.
